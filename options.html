Region Snap settings

Image format

Copying to the clipboard always uses PNG. JPEG has no transparency, so cut corners are white.

Corners
Default action

Used by Enter, the keyboard shortcut and the popup. The toolbar buttons always do what they say.

Capture delay

Counts down before a region is captured, so you can open a menu or hover first. Esc stops the countdown. A full-page capture starts at once.

Burst

Shots

Time between shots

The burst button in the toolbar takes this many shots of the region, each saved as its own numbered file. Chrome may ask once to allow several downloads from the site.

Capture on change

Stop after this many shots

While watching, the region is saved each time its content changes, up to this many shots. The toolbar button or Esc stops it sooner.
